# Kung Fu Legacy — Assumption Register
**Status:** Permanent working document, maintained continuously through Execution Mode. Every major recommendation in every execution-phase document should have a corresponding entry here, marked Assumed / Tested / Validated. Never let an assumption get treated as evidence because it appears in a confident-sounding document.

**Legend:**
- **Assumed** — a reasoned judgment call, not yet checked against real data or real-world outcome.
- **Tested** — checked against something concrete (a document, the live code, a real number Rafael supplied) but not yet proven out in practice.
- **Validated** — confirmed by actual operational outcome (a real applicant, a real payment, a real cohort).
